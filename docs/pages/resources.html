Resources

Documentation, tools, and references for APIs and web scraping

TipTakeaway for researchers

Always check for an official API first. When there isn’t one, use polite + rvest for static sites and Playwright for dynamic web applications.

APIs

Literature and trials

  • PubMed E-utilities: reproducible literature searches, PMID metadata, screening datasets
  • ClinicalTrials.gov API: trial registry metadata, eligibility criteria, reporting compliance

Terminologies and coding

  • UMLS REST API: crosswalk SNOMED CT, ICD-10, CPT, and LOINC through UMLS concept IDs (CUIs). Needs a free UTS account
  • RxNav and RxNorm APIs: drug concepts, ingredients, and RxTerms hierarchies
  • VSAC SVS API: NLM value set expansions and OIDs

EHR and patient care

  • MedlinePlus Connect: link diagnosis and drug codes to patient information
  • OHDSI Athena: standardized vocabularies for the OMOP Common Data Model
  • REDCap: export and import study data. Ask your REDCap administrator for an API token for your project

Surveillance and FDA

  • openFDA: adverse event reports (FAERS), drug labels, device recalls
  • CDC WONDER API: mortality and underlying cause of death
  • Socrata API docs: the $select, $where, and $limit syntax used by CDC and many state data portals

Demographics and local data

  • Census Developer Portal: population denominators and social determinants of health. Needs a free key
  • Census Reporter: search for ACS tables and variable codes
  • CT Open Data Portal: Connecticut health and policy datasets (Socrata)

Web scraping

R tools and ethics

  • rvest: the core static HTML parser (html_element(), html_text2(), html_table())
  • polite: checks robots.txt and manages crawl delays for you

Browser automation

  • Playwright: modern browser automation for JavaScript-heavy pages, clicks, dropdowns, and downloads
  • RSelenium: browser automation from R

Selectors and inspecting pages

  • CSS selectors (MDN): target elements by class (.class), ID (#id), or attribute ([attr=val])
  • XPath syntax (W3Schools): navigate the HTML document tree

Compliance

  • robotstxt (R package): check crawler rules in R with paths_allowed()
  • The Robots Exclusion Standard: what Disallow and Crawl-delay mean

Health data examples

  • CDC FluView Interactive: a dynamic web app (the Playwright example in Lesson 2)
  • WHO Data Portal: global health indicators
