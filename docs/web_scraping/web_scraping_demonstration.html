Web Scraping Demonstrations in R

Web Scraping Demonstrations

This document demonstrates several approaches for extracting structured web data using R.

The examples cover fundamental static scraping techniques using rvest, ethical rate-limiting and domain rule parsing with polite and robotstxt, XPath/CSS element targeting, handling multi-table extractions, and dynamic browser automation using playwright.

0. Setup

Reference: The Web Scraping Data Journey

Every web scraping example in this document follows the same data journey:

Target URL ──► HTML/DOM Response ──► Select & Target Nodes ──► Parse Text/Tables ──► Data Frame (Tibble) ──► Save Snapshot & CSV

Stage What happens
Target URL Define the specific web endpoint or directory listing containing the target data
HTML/DOM Response Server returns the raw markup tree parsed by read_html() or rendered via playwright
Select & Target Nodes html_element() or html_elements() locate nodes via XPaths or CSS selectors
Parse Text / Tables html_table(), html_text2(), or html_attr() extract structured data into memory
Data Frame / Tibble clean_names() and dplyr transform raw text into analysis-ready columns
Save Snapshot & CSV write_html() preserves the raw audit snapshot; write_csv() exports processed data

Reference: The Research Data Workflow (Web Scraping)

Each scraping script in this document follows a six-step research workflow:

Step What it means
1. Identify source + inspect DOM Review robots.txt, Terms of Service, and target page layout via browser Developer Tools
2. Draft selector strategy Identify unique XPaths (e.g., //*[@id="mwAaI"]/table) or CSS classes (e.g., .wikitable)
3. Request web page Download HTML with read_html() or establish an ethical session using polite::bow()
4. Extract + clean Parse tabular nodes with html_table() and clean column names using janitor::clean_names()
5. Save raw + processed data Write static HTML snapshots to disk for auditability; export cleaned tibbles as CSVs
6. Record provenance Document the target URL, extraction selectors, scraping timestamp, and session metadata

Reference: Key Web Scraping Terminology

Term Definition
DOM Tree Document Object Model; the hierarchical tree structure representing HTML elements
CSS Selector Pattern used to select elements based on tags, classes (.class), or IDs (#id)
XPath Language for navigating XML/HTML nodes path-wise (e.g., //table[contains(@class, 'wikitable')])
User-Agent Request header string identifying your scraping session to the web server
robots.txt Text file on domain root specifying forbidden paths and crawl delays for web bots
Static Scraping Extracting data embedded directly in raw HTML returned by the initial server request
Dynamic Scraping Automating a browser engine (e.g., Chromium) to render JavaScript and trigger clicks

Reference: Static (rvest / polite) vs Dynamic (playwright)

Both approaches extract web content, but they operate at different levels of execution:

Feature rvest + polite (Static) playwright (Dynamic)
Execution Direct HTTP fetch; parses raw HTML text Launches full browser (Chromium/Firefox/WebKit)
JavaScript Cannot execute client-side JS Fully executes single-page applications (SPAs)
Interactivity Single fetch; cannot click or type Simulates clicks, form inputs, and dropdowns
Speed & Overhead Fast; minimal CPU/memory usage Resource-intensive; spawns browser process
robots.txt Obeyed automatically via polite::bow() Must be verified explicitly (browser bypasses it)
File Downloads Pulls direct file URLs (href) Intercepts dynamic browser download triggers
Primary Use Case Wikipedia, static news, public listings CDC FluView, interactive portals, complex authentication

💡 Workshop Tip: Steps 3 and 4 directly mirror your code: read_html() pulls the entire document tree into page once, and your custom scrape_by_xpath() function executes Step 4 across multiple table paths.

Static scraping example

Snippet 1: Single Table Scraping (XPath + CSS Alternative)

library(rvest)
library(xml2)
library(janitor)
library(dplyr)

# ==============================================================================
# Step 1: Identify source + inspect DOM
# Source: Wikipedia COVID-19 pandemic page
# Target: Primary "Cases by country and territory" table
# ==============================================================================
url <- "https://en.wikipedia.org/wiki/COVID-19_pandemic_by_country_and_territory"


# ==============================================================================
# Step 2: Draft selector strategy
# In DevTools, right-click the <table> tag -> Copy -> Copy XPath (not "Copy full XPath").
# The short XPath starts from the nearest element with an ID, so it still works
# when the rest of the page layout changes. The full XPath (/html/body/div[3]/...)
# describes the page after the browser has run its JavaScript, and often finds
# nothing in the raw HTML that read_html() downloads.
# ==============================================================================
target_xpath <- '//*[@id="mwAaI"]/table'

# If Wikipedia edits the page and the ID above changes, anchor on the section
# heading instead, which changes much less often:
# target_xpath <- '//*[@id="Total_cases,_deaths,_and_death_rates_by_country"]/ancestor::section[1]//table[contains(@class,"wikitable")]'

# ==============================================================================
# Step 3: Fetch web page
# Download entire raw HTML structure of the web page into R memory ONCE
# ==============================================================================
page <- read_html(url)


# ==============================================================================
# Step 4: Extract & clean data
# Target node -> parse HTML table -> format headers -> safely drop index column
# ==============================================================================
covid_tbl <- page %>%
  # Target element node using resilient section-anchor XPath
  html_element(xpath = target_xpath) %>% 
  
  # Convert HTML table into an R data frame, filling missing cells with NA
  html_table(fill = TRUE) %>% 
  
  # Convert to tibble, repairing non-unique column names
  as_tibble(.name_repair = "unique") %>% 
  
  # Standardize column headers to clean snake_case
  clean_names()

# Safely drop empty leading index column if present
if ("x1" %in% colnames(covid_tbl)) {
  covid_tbl <- covid_tbl %>% select(-x1)
}


# ==============================================================================
# Step 5: Save HTML snapshot & processed data
# Save raw static HTML snapshot for auditability alongside processed dataset
# ==============================================================================
# Preserves source HTML offline so data extraction can be audited, re-parsed, or debugged if the live site changes 
# save in working directory
write_html(page, "covid_page_snapshot.html")


# ==============================================================================
# Step 6: Record provenance
# Log metadata, execution timestamp, and dataset dimensions
# ==============================================================================
cat(
  "--- DATA PROVENANCE LOG ---",
  paste("Target URL :", url),
  paste("XPath Used :", target_xpath),
  paste("Scraped On :", Sys.time()),
  paste("Dimensions :", nrow(covid_tbl), "rows x", ncol(covid_tbl), "cols"),
  sep = "\n"
)

# Preview extracted data
head(covid_tbl, 20)

Snippet 2: Scraping Multiple Tables with a Reusable Function

library(rvest)
library(xml2)
library(janitor)
library(dplyr)
library(readr)

# ==============================================================================
# Step 1: Identify source + inspect DOM
# Source: Wikipedia COVID-19 pandemic page
# Target: Extracting multiple data tables from a single page layout
# ==============================================================================
url <- "https://en.wikipedia.org/wiki/COVID-19_pandemic_by_country_and_territory"


# ==============================================================================
# Step 2: Draft selector strategy
# Define distinct XPaths for each target table node on the page
# ==============================================================================
# (Copied with DevTools -> Copy -> Copy XPath, as in Snippet 1)

# Target the 1st matching table node (Cases table)
path_cases <- '//*[@id="mwAaI"]/table'

# Target the 2nd matching table node (Vaccine/Timeline table)
path_timeline <- '//*[@id="mwAjg"]/table'

# Define re-usable extraction pipeline function with safety checks
scrape_by_xpath <- function(html_page, xpath_string) { 
  tbl <- html_page %>%
    html_element(xpath = xpath_string) %>%          # Target specified table node
    html_table(fill = TRUE) %>%                       # Parse HTML table
    as_tibble(.name_repair = "unique") %>%            # Convert to tibble
    clean_names()                                     # Standardize column headers
  
  # Safely drop empty leading index column if present
  if ("x1" %in% colnames(tbl)) {
    tbl <- tbl %>% select(-x1)
  }
  
  return(tbl)
}


# ==============================================================================
# Step 3: Fetch web page
# Download entire raw HTML structure into local R memory ONCE
# Passing single HTTP GET request prevents redundant network calls
# ==============================================================================
page <- read_html(url)


# ==============================================================================
# Step 4: Extract & clean data
# Execute reusable function across stored target XPaths against cached HTML
# ==============================================================================
covid_tbl_1 <- scrape_by_xpath(page, path_cases)
covid_tbl_2 <- scrape_by_xpath(page, path_timeline)


# ==============================================================================
# Step 5: Save HTML snapshot & processed data
# Save a single static HTML snapshot alongside individual cleaned CSV datasets
# ==============================================================================
write_html(page, "covid_full_page_snapshot.html")
write_csv(covid_tbl_1, "covid_cases_by_country.csv")
write_csv(covid_tbl_2, "covid_timeline_summary.csv")


# ==============================================================================
# Step 6: Record provenance
# Log metadata, selectors used, execution timestamp, and dataset dimensions
# ==============================================================================
cat(
  "--- DATA PROVENANCE LOG ---",
  paste("Target URL   :", url),
  paste("Scraped On   :", Sys.time()),
  paste("Table 1 Path :", path_cases),
  paste("Table 1 Dims :", nrow(covid_tbl_1), "rows x", ncol(covid_tbl_1), "cols"),
  paste("Table 2 Path :", path_timeline),
  paste("Table 2 Dims :", nrow(covid_tbl_2), "rows x", ncol(covid_tbl_2), "cols"),
  sep = "\n"
)

# Preview extracted tables
head(covid_tbl_1)
head(covid_tbl_2)

Dynamic scraping example using python

See python script file, “scraping_using_playwright.py”

Run it in a Jupyter notebook: it uses await at the top level, which only works in a notebook.

import time
from datetime import datetime
from pathlib import Path

import pandas as pd
from playwright.async_api import async_playwright


async def scrape_fluview():
    # ==============================================================================
    # Step 1: Identify source + inspect DOM
    # Source: CDC FluView Interactive Portal
    # Targets: Dynamic SPA app requiring headless browser automation to trigger JS modal
    # ==============================================================================
    url = "https://gis.cdc.gov/grasp/fluview/main.html"

    # Set up local paths for auditability
    save_dir = Path.cwd() / "web_scraping" / "downloads"
    save_dir.mkdir(parents=True, exist_ok=True)

    snapshot_path = save_dir / "cdc_fluview_rendered_snapshot.html"
    raw_zip_path = save_dir / "cdc_fluview_data.zip"
    processed_csv_path = save_dir / "cdc_fluview_data_cleaned.csv"

    # ==============================================================================
    # Step 2: Draft selector strategy
    # XPaths targeting interactive buttons and inputs inside the dynamic modal
    # ==============================================================================
    xpath_header_download = "/html/body/div[1]/header/div[4]/button[2]"
    xpath_custom_option = (
        "//*[@id='downloadDataBody']/ul[1]/li[2]/div/ul/li/label"
    )
    xpath_by_week_tab = "//*[@id='customDownloadPanel']/li[2]/div[1]/div/li/a"
    xpath_modal_download = (
        "//*[@id='downloadDataModal']/div/div/div[3]/button[1]"
    )

    # ==============================================================================
    # Step 3: Fetch web page (Dynamic rendering via Playwright)
    # Launch Chromium browser, accept downloads, and load JS-rendered single-page app
    # ==============================================================================
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=False)
        context = await browser.new_context(accept_downloads=True)
        page = await context.new_page()

        print("Step 3: Navigating to CDC FluView application...")
        await page.goto(url, timeout=90000, wait_until="domcontentloaded")
        await page.wait_for_timeout(8000)

        # ==============================================================================
        # Step 4: Extract & clean data
        # Execute automated DOM clicks and listen for browser download stream
        # ==============================================================================
        print("Step 4: Executing modal interactions...")

        # Click Download button in header
        await page.locator(f"xpath={xpath_header_download}").click(
            timeout=60000
        )
        await page.wait_for_timeout(3000)

        # Select Custom Download
        await page.locator(f"xpath={xpath_custom_option}").click(timeout=60000)
        await page.wait_for_timeout(2000)

        # Click By Week tab
        await page.locator(f"xpath={xpath_by_week_tab}").click(timeout=60000)
        await page.wait_for_timeout(2000)

        # Set up download listener BEFORE clicking the trigger button
        async with page.expect_download() as download_info:
            await page.locator(f"xpath={xpath_modal_download}").click(
                timeout=60000
            )

        download = await download_info.value

        # ==============================================================================
        # Step 5: Save HTML snapshot & processed data
        # Capture rendered DOM snapshot alongside raw download payload and CSV dataset
        # ==============================================================================
        # Save raw HTML DOM tree snapshot
        html_content = await page.content()
        snapshot_path.write_text(html_content, encoding="utf-8")

        # Save binary download payload
        await download.save_as(raw_zip_path)

        # Clean browser environment
        await browser.close()

        # Extract/load raw CSV into pandas (CDC packages extra header rows in download)
        df_cleaned = pd.read_csv(raw_zip_path, skiprows=1)
        df_cleaned.columns = (
            df_cleaned.columns.str.strip().str.lower().str.replace(" ", "_")
        )
        df_cleaned.to_csv(processed_csv_path, index=False)

        # ==============================================================================
        # Step 6: Record provenance
        # Document target source, selectors used, execution timestamp, and metrics
        # ==============================================================================
        log_entry = f"""
--- DATA PROVENANCE LOG ---
Target URL      : {url}
Execution Time  : {datetime.now().strftime("%Y-%m-%d %H:%M:%S")}
HTML Snapshot   : {snapshot_path.name}
Raw Data File   : {raw_zip_path.name}
Cleaned Data    : {processed_csv_path.name}
Dataset Dims    : {df_cleaned.shape[0]} rows x {df_cleaned.shape[1]} cols
---------------------------
"""
        print(log_entry)
        print(f"✅ Data processed successfully! Preview:\n{df_cleaned.head(3)}")


# Jupyter execution call
await scrape_fluview()


# Pass compression=None so Pandas treats it as a plain CSV text file
cdc_fluview_data = pd.read_csv(
    "web_scraping/downloads/cdc_fluview_data.zip",
    skiprows=1,
    compression=None
)

# Clean column headers
cdc_fluview_data.columns = (
    cdc_fluview_data.columns.str.strip().str.lower().str.replace(" ", "_")
)

# View preview
cdc_fluview_data.head()
